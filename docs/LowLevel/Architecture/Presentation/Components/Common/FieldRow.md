# FieldRow

## Purpose
Provide a reusable labelled field row with helper and validation message regions.

## Consumes
- field label
- field control slot
- helper text
- validation message
- required and disabled state

## Emits
- none directly

## Notes
- `FieldRow` keeps forms readable by standardising label-control-help structure.
- Concrete validation logic remains in the owning view or feature component.
