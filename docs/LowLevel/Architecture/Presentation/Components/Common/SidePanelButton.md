# SidePanelButton

## Purpose
Provide compact action buttons for side-panel controls and inline row actions.

## Consumes
- label or icon
- selected, disabled, or danger state
- optional count or badge

## Emits
- `clicked`

## Notes
- `PlayerPanel`, `HistoryPanel`, `AnalysisPanel`, and `GameControlPanel` use `SidePanelButton`.
- This family is optimised for dense panel layouts rather than menu or dialog actions.
